(e) `approved_signal.client_request_id` provides sender-scoped idempotency; replays never resurrect a revoked signal. (f) `my_receipts` is sender-only (recipients could otherwise learn of revoked or no-nudge disclosures); new sender-only `my_signals` view; `my_nudges` rechecks source-signal standing on every read. (g) Any preset or assignment version change (including broadening) stales older signals. (h) Local vault design in `src/vault/DESIGN.md`: PBKDF2-SHA-256 600k passphrase KEK plus HKDF recovery-code KEK, each wrapping one random AES-GCM-256 DEK; single device, no escrow.
